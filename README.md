## ⭐ Featured Projects

### 🛡️ [Voice Integrity Verification](https://github.com/aayash317-svg/Ai_voice-_cloning)
> Real-time AI security engine that detects AI-cloned voices, synthetic speech, and deepfakes during audio calls and uploads.

- Dual-model ensemble: PyTorch SincNet (raw waveform) + 63-feature Random Forest classifier
- 3-stage progressive threat scoring with WebSocket streaming
- Zero-retention privacy: audio processed in RAM ring buffer, never written to disk
- SHA-256 cryptographic audit ledger for every call inspection
- Validated: **0.9882 ROC-AUC** · **6.12% EER**
- Deployed on Render with Docker

**Tech:** `Python` · `FastAPI` · `PyTorch` · `librosa` · `scikit-learn` · `Docker` · `WebSockets`
